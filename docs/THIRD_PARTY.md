SPDX-License-Identifier: GPL-3.0-only

The Package Cleaner icon (`data/package-cleaner.svg`) is original artwork created for this project, not an imported icon-pack asset. It is distributed under the same GPL-3.0-only license as the project. The About-page screenshot depicts that artwork and the project's own interface. The main review screenshot uses entirely fabricated application names, sizes and queue data, rendered by the real GTK frontend with the Mint theme. Neither screenshot contains a real installed inventory or private paths.

No third-party Python source, fonts, binary dependencies or icon packs are vendored. Python, python-apt, PyGObject, GTK, GLib, libflatpak, APT/dpkg, sudo, desktop themes and external application icons are used from the operating system and retain their respective copyright and license terms. Themed interface icons are resolved at runtime rather than redistributed as assets. The complete GPLv3 license document in LICENSE retains the Free Software Foundation's notice unchanged.

The newly authored AppStream catalog metadata is separately dedicated under CC0-1.0 for software-catalog redistribution; see CC0-1.0.txt. Program code and artwork remain GPL-3.0-only.
